# MS8100 详情页设计说明

依据用户提供的 MS8100 完整移动端设计稿和 `C:\Users\lengjing\Desktop\文档\官网\3` 中的切图，重构 `/products/ms8100`。页面在手机端铺满，在桌面端沿用项目既有的手机宽度容器，并尽量逐段还原设计稿的排版、色彩、间距和视觉层级。

- 只修改 MS8100 详情页及其专属资源。

## 页面结构

1. Hero：使用现有 `src/assets/ms8100/bg.png`，展示 MS8100、LC-MS/MS、产品副标题和购买咨询按钮。
2. 四极杆：深灰背景、标题与四条蓝色圆点文案，使用 `bg 拷贝 (2).png` 展示四极杆结构。
3. 离子源：黑色背景、标题与四条红色圆点文案，使用 `bg 拷贝.png` 展示离子源结构。
4. 核心亮点：六个两列卡片，使用代码排版文字和简洁视觉图形，保持设计稿的 2×3 网格、暗色渐变与红蓝强调色。
5. 超凡稳定性与重现性：使用设计稿说明文字与 `图1 (1).png` 稳定性图表。
6. 产品对比：使用 `图层 729.png`、`7.png`、`6.png` 构建三行产品表格，并使用 `信噪比.png` 展示灵敏度对比。

## 实现方式

- 删除当前随机生成 Recharts 数据及旧版拼接内容，避免刷新时图表变化和乱码继续存在。
- 页面内容以静态 React 数据结构驱动，重复的圆点列表和亮点卡片通过数组映射渲染。
- 样式只使用 Tailwind utility class，遵循现有项目规范。
- 动画只保留轻量的首屏淡入，不增加滚动劫持或复杂交互。
- 图片提供中文 `alt`；按钮使用原生 `button` 并维持明确的导航行为。

## 响应式与视觉标准

- 页面设计基准宽度为 375px，与设计稿比例一致。
- 外层宽度沿用 `Layout` 的 `max-w-md`，内容不产生横向滚动。
- 标题、正文、表格在 320–448px 宽度内不重叠、不截断。
- 背景按模块在近黑色与深灰色间切换，强调点使用品牌红和科技蓝。
- 图片使用明确的宽高或纵横比，减少加载时布局跳动。

## 验收与验证

- 页面顺序、文案层级和切图使用与完整设计稿一致。
- 页面不存在当前源码中的乱码。
- Hero 的购买咨询按钮可跳转到正确地址。
- 不出现随机图表、横向溢出或图片变形。
- 执行 `npm run lint` 和 `npm run build` 均成功。
- 在本地浏览器以移动端宽度检查完整页面截图，并与设计稿比对。
